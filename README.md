# machine_learning_2026

Updated lecture examples:

- [ID3 Play Tennis](decisionTree/README.md): categorical entropy and information gain, using the exact 14-row tennis problem in 15.+Decision+tree+_+ID3.pdf. Includes a highlighted decision tree graph.
- [Linear SVM](svm_diabetes_triage/README.md): binary linear classification, margins and genuine support vectors following svm15.pdf. Includes the input's score calculation and decision plot.

- [K-means Dataset Lab](kmeans/README.md): learns centers from three CSV datasets with user-selected K, training replay, and nearest-center decision explanations.

Each project keeps its algorithm in a separate module and documents training parameters, data changes, local startup and tests in its README.
